# TGambs.github.io

This website is the project portfolio for Tom Gambro
It can be seen at - https://tgambs.github.io/

It currently contains:
- UFAC Application
  - A USB Formatting & Audio Conversion application
- KBR
  - A post-quantum key pair generator, encrypter, and decrypter
  - Using standarised ML-KEM768 with AES256-GCM for secure encryption
  - Utilises Stronghold for secure private key storage on the user's device
